# Eldervale v1.5.1 — responsive run and a clear battlefield

Enemy attacks no longer draw red ground circles. Their windup, projectiles,
charges, damage and dodge opportunities remain functional.

Movement was compared directly against the read-only Dawnbound source at
`E:\Roguelike Opus 55`. A short thumb throw reaches full run before the visible
joystick rim. Input has a small dead zone and a continuous walk-to-run curve.
Acceleration and turning use the reference's exponential response: about 70%
of full speed in 50ms, with quicker braking. Warden/arcanist full run is 82
world pixels/s; ranger retains its relative speed advantage. Gentle walking
retains its previous pace.

The character faces the input direction immediately, with footfall phase
preserved across turns and gait changes. Native run animation has its original
full cadence at maximum speed. The full-screen world and collapsed menus from
v1.5 are retained.

AdMob banner, interstitial and rewarded use the official Google demo IDs.
The menu reserves the SDK-reported adaptive banner height above Android's
navigation area. Banner layouts are checked at 360, 390 and 412px widths with
50 and 90px reservations, alongside real native demo-ad checks. Gameplay hides
the banner. Remove Ads still needs a live Play product/key before real checkout.

Current verification evidence is recorded in [verification.md](verification.md).
All previous versioned Android release files and the existing signing key are
preserved. No save migration is required.
